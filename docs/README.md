## 🔄 Document Lifecycle

- **Planning docs** - Created before implementation, updated as requirements evolve
- **Architecture docs** - Updated when major architectural decisions are made
- **Development docs** - Living documents, updated with new patterns and workflows
- **Design docs** - Updated when new design patterns or themes are added
- **Implementation plans** - Created per feature/phase, archived when complete

---

## 📝 Contributing to Documentation

When adding or updating documentation:

1. **Place in correct category** - Use existing structure
2. **Update this README** - Add to document index
3. **Use clear naming** - Descriptive filenames (e.g., `AUTHENTICATION_GUIDE.md`)
4. **Link related docs** - Cross-reference when helpful
5. **Keep it current** - Archive outdated docs to `docs/archive/`
